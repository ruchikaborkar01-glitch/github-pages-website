# Task 5: Static Website with GitHub Pages

I created a simple HTML website and deployed it using GitHub Pages.

## Steps
1. Created index.html and style.css
2. Pushed the files to a new GitHub repository
3. Went to Settings → Pages and selected the main branch and root folder
4. Got the live website link
